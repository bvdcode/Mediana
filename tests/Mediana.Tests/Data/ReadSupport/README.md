These fixtures contain synthetic video from FFmpeg's `testsrc2` and synthetic audio from `sine`.

- `dv-ntsc.avi` has four NTSC DV25 frames in 4:1:1. The compressed raw reference contains the first and third decoded pictures.
- `ffv1-small.avi` and `ffv1-slices.avi` use FFV1 versions 1 and 3, with a keyframe every three pictures.
- `mixed.ts` contains H.264 and AAC. `mixed.mpg` contains MPEG-2 video and Layer II audio. `mixed.wmv` contains WMV2 and WMA2.

The packet and frame checksums were generated by FFmpeg.
