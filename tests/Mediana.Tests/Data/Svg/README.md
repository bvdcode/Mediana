# SVG pixel references

These original synthetic scenes and 352 filter reference hashes originate from
Render.NET commit `03cb502`, under the MIT license, copyright 2026 Vadim Belov.
The filter hashes were recorded against version 0.3.18 before its scanline and
buffer optimizations. They are regression references, not browser conformance
results. Scenes cover blur, morphology, edge modes, transparency, sRGB/linearRGB
and transforms. No imported artwork is included.
