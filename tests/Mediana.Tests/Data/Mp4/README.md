# MP4/MOV fixtures

The clips contain generated test patterns and tones, with no external source media.
They exercise AVC High with B-frames and AAC mono in fast-start MP4, and AVC Baseline
video-only MOV with the movie metadata after the media data.

The checked-in JSON files record source SHA256, stream configuration hashes and
every packet's original media PTS/DTS, duration, size, position, sync flag and SHA256.
Edit-list application is disabled in the reference command so packet times remain
in the track's original media timeline. The reader exposes edits separately.

Generation used FFmpeg/ffprobe 6.1.1. These tools are used to prepare and independently
inspect fixtures; building and running Mediana and its tests does not require them.
Encoder versions can change the generated bytes; use the corresponding reference
JSON when updating a fixture.

```sh
ffmpeg -v error -nostdin -y -f lavfi -i testsrc2=size=64x48:rate=5:duration=1.6 -f lavfi -i sine=frequency=440:sample_rate=48000:duration=1.6 -map_metadata -1 -c:v libx264 -preset medium -pix_fmt yuv420p -g 5 -bf 2 -c:a aac -b:a 64k -movflags +faststart -shortest avc-aac.mp4
ffmpeg -v error -nostdin -y -f lavfi -i testsrc2=size=80x48:rate=5:duration=1.2 -map_metadata -1 -c:v libx264 -profile:v baseline -g 5 -bf 0 -an avc-tail.mov
ffprobe -v error -ignore_editlist 1 -show_streams -show_format -show_packets -show_data_hash sha256 -show_entries stream=index,codec_name,codec_type,codec_tag_string,width,height,sample_rate,channels,time_base,duration_ts,extradata_size,extradata_hash:packet=stream_index,pts,dts,duration,pos,size,flags,data_hash:format=duration -of json input.mp4
```

The sha256 root field is the lowercase SHA256 of the complete fixture file.
