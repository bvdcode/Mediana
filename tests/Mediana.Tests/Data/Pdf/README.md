# PDF references

`graphics.pdf` and `scan-globals.pdf` are original synthetic files from Render.NET
commit `03cb502`, authored by Vadim Belov under MIT. Their contents are vector
geometry, generated images and original text. The latter contains a JBIG2 image,
an ASCIIHex filter and an indirect Flate-compressed global symbol dictionary.
No third-party document content is included.

`report.pdf` is an original synthetic report generated by `generate.py` using
ReportLab/Pillow as development tools. It embeds a CC0 Aileron TrueType subset
from Mediana.Images.Svg/Fonts; font provenance is recorded in that directory.
The document uses an RGB chart, original text and a generated 24x24 RGB image.
The generator uses deterministic document IDs/timestamps.

`manifest.json` records encoded input hashes. `graphics.rgba.gz` and
`report.rgba.gz` are full-page 96-DPI RGBA references from Poppler 26.05.0
(`pdftoppm -r 96 -f 1 -singlefile -png`). `scan.rgba.gz` contains the original
synthetic source image from Render.NET/Tests/Fixtures/Pdf/Scans/source.png.
`references.json` records dimensions and decoded-pixel SHA-256 values.

Tests verify dimensions and every channel: page previews allow mean RGB error
3/255 and require at least 95% of pixels within 8 per RGB channel, with exact
alpha. The extracted scan must match every byte. These synthetic comparisons
cover the declared preview subset, not general PDF conformance. Tests also
construct compressed-object/xref streams, crops, rotations, forms, masks and
malformed/limited inputs without external runtime dependencies.
