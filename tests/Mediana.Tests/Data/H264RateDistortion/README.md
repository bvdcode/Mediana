The corpus contains fourteen complete 80-picture sequences encoded with CABAC and `H264MacroblockAnalysis.RateDistortion`. Predictive pictures use a strict zero-quantized-residual P_SKIP probe before motion estimation, distinct spatial and temporal motion seeds, cardinal half-pixel/quarter-pixel refinement and bounded Intra16 rate-distortion comparison. Inputs cover constant planes, horizontal translation, chroma motion, vertical translation with a scene change, cropped macroblock edges and variable frame duration. Quantizers include 0, 12, 26, 38 and 51. Three additional sequences exercise constrained variable rate with short buffer envelopes and adaptive slice quantizers. Each sequence contains two IDR intervals; all sequences together contain 1120 pictures.

Inputs are generated by `H264TemporalEncodingTestInput`. Complete MPEG-TS output was decoded with the independent native H.264 decoder in FFmpeg 6.1.1, one decoder thread, passthrough timestamps and raw YUV420 output. Every stored pixel matched Mediana decoding and the accepted reconstructed reference samples of the encoder. `references.json` records the complete transport and decoded-pixel hashes. Gzip contains only raw reference pixels; tests compare the complete decompressed sequence and exact transport hash.

Generation and validation use no imported video or audio samples.
