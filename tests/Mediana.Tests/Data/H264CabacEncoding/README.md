The corpus contains complete independently decoded YUV420 sequences for Main-profile CABAC encoding. Each sequence has 80 frames and two IDR intervals. Inputs cover constant planes, horizontal translation, chroma motion, vertical translation with a scene change, cropped macroblock edges and variable frame duration. Quantizers cover 0, 12, 26, 38 and 51. Three additional sequences exercise constrained variable rate with short buffer envelopes and adaptive slice quantizers. All fourteen complete sequences contain 1120 frames.

Sources are generated by `H264TemporalEncodingTestInput`. Encoded MPEG-TS was decoded with FFmpeg 6.1.1 using the native H.264 decoder, one decoder thread, passthrough timestamps and raw YUV420 output. Every stored pixel matched the separately reconstructed Mediana picture. `references.json` records hashes of the complete transport and decoded pixels. Gzip stores only the raw reference pixels; tests compare the complete decompressed sequence.

Generation and validation use no imported video or audio samples.
