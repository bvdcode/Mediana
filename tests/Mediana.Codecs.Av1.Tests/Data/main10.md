The `main10*.obu` sequences contain twelve ten-bit Main-profile pictures each,
encoded by AOM 3.8.2 with a six-picture-per-second clock, constant quantizer 28,
CPU setting 4, no lookahead, and a keyframe interval longer than the sequence.
The encoder uses BT.709 color labels and left chroma positioning. Input samples
contain independent low-bit detail; they are not shifted eight-bit pictures.

| Sequence | Visible size | Additional configuration |
| --- | --- | --- |
| main10Default | 160 × 136 | Default inter prediction and all frame filters |
| main10Odd | 193 × 137 | Partial luma and chroma edges |
| main10Mono | 65 × 73 | Monochrome |
| main10Tiles | 384 × 136 | Two tile columns |
| main10Grain | 193 × 137 | Film-grain test vector 16 |
| main10Superres | 192 × 136 | Fixed super-resolution denominator 13 |
| main10SuperresGrain | 193 × 137 | Denominator 14 and grain vector 16 |

For each plane and frame, source coordinates wrap after adding
`frame * (plane + 2)` horizontally and `frame * (plane + 1)` vertically.
The unsigned sample is
`64 + (5*x + 7*y + ((x/17) XOR (y/13))*31 + ((x*y + frame*19 + plane*37) AND 15)) % 896`,
using integer division and plane-local dimensions. Chroma dimensions round up.

The adjacent `.sha256` files were generated by FFmpeg 6.1.1 with libdav1d 1.4.1
and contain `AV1HASH1`, a little-endian signed 32-bit picture count, unsigned
16-bit visible width and height, then one SHA-256 digest per complete visible
picture. Each digest covers native ten-bit samples stored as little-endian
unsigned 16-bit words, in Y/U/V plane order, excluding stride padding. Monochrome
digests cover only Y. No precision conversion precedes hashing.

The public decoder must reproduce every digest over two complete runs separated
by reset. Additional checks retain displayed frames while references change,
cancel input, reset the decoder, and require all allocator leases to be released.
The filtered inter sequences also exercise scaling primary CDEF strength before
variance adjustment and deriving tap parity from the adjusted strength.

The MP4 and Matroska variants copy `main10Default.obu` without re-encoding.
Remuxing assigns a time base of 1/6000 and packet timestamps and durations in
steps of 1000 ticks, preserving a two-second presentation. Container checks
compare the same independent picture hashes during sequential reading and
repeated nonsequential seeks, using the exact container timestamps as targets.
