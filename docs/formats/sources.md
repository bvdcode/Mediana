# Format specifications and discovery sources

Entries link to standards bodies, format owners or the primary implementation's
documentation. A family-level reference must be narrowed to the exact revision,
part, profile and clauses in the implementation and fixture documentation.
Discovery entries identify targets; they do not establish conformance requirements.

<a id="iso-bmff"></a>
